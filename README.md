# Upgrade Tree Editor

인크리멘탈 게임의 **업그레이드 노드와 의존성**을 설계하는 웹 툴.
재화·비용·해금 조건·효과를 편집하고, 결과를 JSON으로 뽑아 AI와 주고받거나 게임에 그대로 쓴다.

## 실행

빌드가 필요 없다. `index.html`을 브라우저로 열면 끝.

```bash
# 그냥 열기
open index.html          # macOS
start index.html         # Windows

# 또는 로컬 서버
npx serve .
```

## 주요 기능

- **그래프 뷰**: 의존 깊이별 자동 정렬. 노드를 선택하면 선행/후속 경로가 강조됨. 실선 = AND, 보라 점선 = OR
- **노드 편집**: 비용(기본 × 증가율^(Lv−1)) + 레벨별 가격표, AND/OR 해금 조건(노드 레벨 · 재화 도달 · 자유 텍스트), 구조화된 효과, `{value1}` 템플릿 설명, 디자인 메모, 상태
- **검증기**: 순환 의존, 끊긴 참조, 최대 레벨 초과 요구, 생산처 없는 재화 등
- **AI에게 넘기기**: 컨셉 + 스키마 설명 + 현재 JSON + 응답 규칙을 한 번에 복사
- **불러오기**: JSON 파일 또는 AI 응답 전체 붙여넣기 → 변경점(추가/삭제/수정) 확인 후 적용
- **자동 저장**(localStorage), 실행 취소/다시 실행

## 단축키

| 키 | 동작 |
|---|---|
| `N` | 새 노드 (선택된 노드를 요구하는 노드로 생성) |
| `F` | 전체 보기 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `Esc` | 선택 해제 · 모달 닫기 |

## 데이터 관리

- 진짜 원본은 **JSON 파일**이다. localStorage 자동 저장은 임시 보관용.
- 작업이 끝나면 `JSON 내보내기`로 저장해서 **각 게임 레포**에 커밋한다. (예: `Assets/Data/upgrades.json`)
- 예시 데이터: [`examples/stranded-god.json`](examples/stranded-god.json)
