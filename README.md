# Upgrade Tree Editor

인크리멘탈 게임의 **업그레이드 노드와 의존성**을 설계하는 웹 툴.
재화·비용·해금 조건·효과를 편집하고, 결과를 JSON으로 뽑아 AI와 주고받거나 게임에 그대로 쓴다.
프로젝트를 여러 개 만들어 게임·챕터별로 나눠 관리한다.

## 실행

빌드가 필요 없다. `index.html`을 브라우저로 열면 끝.

```bash
# 그냥 열기
open index.html          # macOS
start index.html         # Windows

# 또는 로컬 서버
npx serve .
```

## 주요 기능

- **프로젝트**: 시작하면 프로젝트 목록에서 고른다. 새로 만들기 · 복제 · 이름 변경 · 삭제 · JSON 파일로 시작, 프로젝트마다 연결된 파일이 따로 기억됨
- **그래프 뷰**: 의존 깊이별 자동 정렬 + 드래그로 위치 보정(⌖ 표시). 노드를 선택하면 선행/후속 경로가 강조됨. 실선 = AND, 보라 점선 = OR, 색 = 상태
- **드래그로 연결**: 노드 오른쪽 점을 다음 노드로 끌면 선행 조건이 생김 (순환은 자동 차단)
- **여러 개 한꺼번에**: Ctrl(⌘)+클릭으로 다중 선택 → 상태·태그·선행 조건 일괄 변경, 줄맞춤, 일괄 삭제
- **묶음은 태그로**: 고정된 계층(시대 등)은 없다. 태그로 분류하고 목록에서 상태·태그로 거르거나, 아예 프로젝트를 나눈다
- **비용 곡선 비교**: 여러 노드의 레벨별 가격 / 누적 합계를 로그·선형 눈금으로 겹쳐 보기
- **노드 편집**: 비용(기본 × 증가율^(Lv−1)) + 레벨별 가격표, AND/OR 해금 조건(노드 레벨 · 재화 도달 · 자유 텍스트), 구조화된 효과, `{value1}` 템플릿 설명, 디자인 메모, 상태
- **검증기**: 순환 의존, 끊긴 참조, 최대 레벨 초과 요구, 생산처 없는 재화 등
- **AI에게 넘기기**: 컨셉 + 스키마 설명 + 현재 JSON + 응답 규칙을 한 번에 복사
- **불러오기**: JSON 파일 또는 AI 응답 전체 붙여넣기 → 변경점(추가/삭제/수정) 확인 후 **원하는 항목만 골라 적용**
- **로컬 파일 저장**: 저장 위치를 한 번 고르면 이후 `Ctrl+S`로 같은 파일에 덮어쓰기 (자동 저장 옵션 포함)
- **자동 저장**(localStorage), 실행 취소/다시 실행

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+S` / `Ctrl+Shift+S` | 연결된 파일에 저장 / 다른 이름으로 저장 |
| `N` | 새 노드 (선택된 노드를 요구하는 노드로 생성) |
| `Ctrl+A` | (그래프에서) 보이는 노드 전체 선택 |
| `Ctrl`(⌘)`+클릭` | 노드 다중 선택 |
| `F` | 전체 보기 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `Esc` | 선택 해제 · 모달/프로젝트 목록 닫기 |

## 데이터 관리

- 진짜 원본은 **JSON 파일**이다. localStorage 자동 저장(프로젝트별)은 임시 보관용.
- 상단 `파일로 저장`(또는 `Ctrl+S`)으로 **게임 레포 안의 경로**를 한 번 고르면(예: `Assets/Data/upgrades.json`), 이후 `Ctrl+S`가 그 파일을 바로 덮어쓴다. 연결된 파일 이름은 상단 바에 표시되고, 저장하지 않은 변경은 노란 점으로 알려준다.
- 프로젝트 탭에서 **자동 저장**을 켜면 수정할 때마다 그 파일에 기록된다.
- 파일 연결은 Chrome·Edge에서 동작한다(File System Access API). 지원하지 않는 브라우저에서는 `내보내기 → 다운로드`로 저장한다.
- 예시 데이터: [`examples/stranded-god.json`](examples/stranded-god.json)
